# トークン

値は `src/styles/theme.css` で決めている。ここに並べているのは、その変数を読んで描いたもの。

## 色

基本は黒と白と、グレーの濃淡。赤（primary）は画面ごとに 1〜2 か所にだけ使う。

## 文字

書体は癖のないサンセリフ 1 つ。順序は文字の大きさと太さで付ける。

<Typeset
  fontFamily='"Helvetica Neue", Helvetica, Arial, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif'
  fontSizes={[12, 14, 16, 24, 30]}
  fontWeight={400}
  sampleText="取引 1,234 円 Tsuke"
/>

## 線と角

- まとまりの始まりは黒の細線（`border-t border-foreground`）、行の境目は薄い細線（`border-b`）
- 角丸と影は使わない（`--radius: 0`）

  <div className="border-b border-foreground/40 py-1 text-sm">入力欄の下線</div>
</div>

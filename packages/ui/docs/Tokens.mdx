# トークン

値は `src/styles/theme.css` で決めている。ここに並べているのは、その変数を読んで描いたもの。

## 色

基本は黒と白と、グレーの濃淡。赤（primary）は画面ごとに 1〜2 か所にだけ使う。

## 文字

書体は癖のないサンセリフ 1 つ。順序は文字の大きさと太さで付ける。

  fontWeight={400}

/>

## 線と角と影

- まとまりの始まりは黒の細線（`border-top: 1px solid var(--foreground)`）、行の境目は薄い細線（`var(--border)`）
- 角丸は使わない
- 入力欄・選択欄は枠で囲まず、下線だけを引く
- 影は浮く面にだけ付ける（メニュー・ポップアップ・トーストは `--popup-shadow`、ダイアログは `--dialog-shadow`）

<div style={{ display: "grid", gap: 16, maxWidth: 360, fontSize: 14 }}>

  <div style={{ paddingBlock: 8, borderBottom: "1px solid var(--border)" }}>行の境目</div>
  <div

      borderBottom: "1px solid color-mix(in oklab, var(--foreground) 40%, transparent)",
    }}
  >
    入力欄の下線
  </div>
  <div style={{ padding: 12, boxShadow: "0 0 0 1px var(--input), var(--popup-shadow)" }}>
    浮く面（--popup-shadow）
  </div>
</div>

# 画面のデザインの方針

台帳の Web 画面（apps/ledger）と拡張機能のサイドパネル（apps/extension）は、スイススタイル（国際タイポグラフィック様式）を下敷きにする。大事にするのは機能美で、要素は情報を伝えるか操作を助けるためにだけ置く。

色・書体・角丸のトークンと、両方で使う部品・型はこのパッケージ（`@tsuke/ui`）に置き、両方から読み込む。

- トークン：`src/styles/theme.css`
- 部品（shadcn/ui）：`src/components/`
- 型（ラベル付きの欄、円の単位、合計、エラーの知らせ、見出しと中身のまとまり）：`src/patterns/`
- 見本：`pnpm --filter @tsuke/ui run storybook` で開く Storybook

## 判断の基準

その要素がなくなったときに、情報が減るか、操作しにくくなるか。どちらでもなければ置かない。

- 置かない：順番に意味のない番号（「01 支出」など）、区切りのためだけの太い線、カードの影や角丸、何も表さない色
- 置く：前後の月や別の画面へ移る矢印、比率を表す横棒、今いる画面を示す下線、お金の向きを示す「+」、行やまとまりの境目を示す罫線

## グリッド

- 広い画面では 12 列のグリッドにし、見出しを左の 3 列、中身を右の 9 列に置く。要素は中央に寄せず左揃えにする
- 狭い画面（`md` より狭い）では 1 列にし、見出しを中身の上に積む

## 文字

- 書体は癖のないサンセリフ 1 つにする（Helvetica Neue / Helvetica / Arial、和文はヒラギノ角ゴシック / Noto Sans JP）
- 順序は文字の大きさと太さで付け、囲みや色に頼らない。その画面で一番大事なもの（集計の月、合計の金額）は大きく出す
- 数字は等幅（`tabular-nums`）にし、金額は右揃えで桁をそろえる
- 金額の入力欄と合計には単位の「円」を小さく細く添える。数字の後ろに置くので、どの行でも桁がそろう。一覧のように見出しや列の名前で金額だと分かる所には付けない

## 線と面

- まとまりは罫線で区切る。まとまりの始まりは黒の細線（1px）、行の境目は薄い細線にする
  - ただし入力欄を並べた行（狭い画面の品目）の境目は、入力欄の下線より濃くする。下線より薄いと、行の境目と欄の下線を取り違える
- 角丸と影は使わない（`--radius: 0`）
- 押せる行はホバーで背景を薄く変え、入力中の欄は線を太くして、触れたときの反応で操作できることを示す

## 色

- 基本は黒と白と、グレーの濃淡
- 赤（`--primary`）をアクセントとして、画面ごとに 1〜2 か所にだけ使う
  - 今いる画面のナビの下線
  - その画面で一番見てほしい数字（集計の収支など）
  - 主ボタン（登録・保存）のベタ塗り。主ボタンは画面に 1 つだけ
- 注意書き（集計に含めない取引、重複の警告、入力の誤り）も赤になるので、色だけに頼らず、必ずアイコンと文言を付ける
- マイナスの金額はふつうにある（クレジットカードの残高、値引きの品目）ので、注意の色にはせず「−」の符号だけで示す
- 収入の金額には「+」を付けてお金の向きを示す。振替と残高調整はお金の出入りではないので、一覧では薄い色にする

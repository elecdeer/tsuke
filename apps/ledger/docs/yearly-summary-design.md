# 年の集計の画面

集計の画面（`/`）の見出しに「月 / 年」の切り替えを置き、年は `/?year=2026` で開く。ナビの項目は増やさない。

## 出すもの

- 年の支出・収入・収支の合計（月の集計と同じ並び）
- 月ごとの支出と収入の棒グラフ。棒を押すとその月の集計へ移る
- カテゴリ別の年の合計。開くとそのカテゴリの月ごとの棒グラフと、内訳ごとの合計が出る

## 決めたこと

- **年は暦年（1 月から 12 月）にする。** 年度や締め日で区切る設定は作らない
- **「常に集計に含める」と「年の集計にのみ含める」の取引を入れる。** 月の集計は「常に」だけのままにする。集計からの除外の種類は増やさない
- **立替と値引きの扱いは月の集計と同じにする。** 月ごとの集計（`summarizeByMonth`）を月と年で共有し、年はそれを足し合わせる。月ごとには残っていても、年で足すと 0 になる内訳とカテゴリは出さない
- **グラフは TanStack Charts（`@tanstack/charts`）で描く。** SVG をサーバーで描け、使う部品だけを読み込める。2026-07 に出たばかりで 1.0 から互換性の約束がある版なので、カタログで版を固定し、上げるときは変更点を確かめる
- **グラフの色は黒とグレーだけにする。** 赤は収支などのアクセントに取っておく（[design.md](design.md)）。系列の色は TanStack Charts が読む `--ts-chart-N` の変数を上書きして決める
- **カテゴリのグラフは開いたときにだけ描く。** カテゴリは数十あり、閉じたものまで描くと重くなるため
- **年の表示では取引の一覧へのリンクを出さない。** 取引の一覧は月ごとにしか絞り込めないため。月のグラフから月の集計へ移って、そこから辿る
- **年の表示は横に払って前後の年へ移らない。** 払う操作は月の表示で月を移すのに使っているため。前後の年へは見出しのリンクで移る

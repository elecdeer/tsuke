# 口座とカテゴリの管理画面

設定の下の `/settings/accounts` で口座を、`/settings/categories` でカテゴリと内訳を管理する。Zaim の CSV の取り込みでしかマスタを増やせないと、切り替えの後に新しいカードや費目を登録できないので作った。

## できること

- **追加。** 並びの最後に入る
- **名前の変更。** 取引と品目はマスタを ID で参照するので書き換えない
- **並び替え。** 上下のボタンで動かす。入力の候補の順番になる
- **アーカイブと元に戻す。** 入力の候補と AI の読み取りの候補から外す。過去の取引と集計はそのまま残る

## 決めたこと

- **消さずにアーカイブする。** スキーマの決まり（参照されているマスタは削除せずアーカイブする）に合わせる。未使用のマスタの削除と統合は、必要になるまで作らない
- **同じ名前はアーカイブ済みのものとも重ねられない。** 名前の一意制約がアーカイブ済みにも効くので、元に戻すよう案内する。支出と収入のカテゴリは別なので、同じ名前を付けられる
- **残高のある口座はアーカイブできない。** 残高の画面の合計はアーカイブした口座を含まないので、アーカイブで合計が黙って変わらないようにする。先の日付の取引も含めて 0 であることを確かめ、残っていれば残高調整を案内する
- **並び替えでは全件の `sort` を振り直す。** 取り込んだマスタの `sort` はすべて 0 で、2 件の入れ替えでは順番が変わらないため。動かす対象はアーカイブしていないものだけ
- **収入のカテゴリには内訳を追加できない。** 収入は内訳を持たない（取り込みでも拒否している）
- **内訳のない支出のカテゴリを作れる。** 支出の入力は内訳を選ぶので、内訳を足すまで選べない。画面にその旨を出す
- **アーカイブは確認のダイアログを挟まない。** 元に戻せる操作なので

## 切り替えとの関係

取り込みはマスタを名前で `INSERT OR IGNORE` する。切り替えの再取り込みより前に名前を変えると、CSV の古い名前のマスタがまた作られて取引がそちらに付くので、名前の変更は切り替えの後にする。追加したマスタは総入れ替えでも消えない。
